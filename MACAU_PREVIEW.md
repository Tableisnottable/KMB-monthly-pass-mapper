# Macau v2 preview

Work happens on `feature/macau-v2`, separately from the Hong Kong release.
Do not deploy this branch over the Hong Kong production Worker while the
Macau bus timetable adapter is incomplete.

## Run

Use Node 22.12 or later. `npm run dev` opens the Chinese preview at `/macau`
and English at `/macau/en`. The Hong Kong planner remains at `/` and `/en`.
`npm run cf:build` stages both cities for the existing free hosting architecture;
route calculation stays in browser background workers. Staging is not deployment.

## Implemented

- Independent, lazily loaded Macau adapter; opening HK does not import Macau data.
- 90 DSAT bus route numbers, 111 direction patterns, 599 bus stop platforms.
- Three LRT lines, six directions, actual OpenStreetMap railway geometry.
- 3,376 OSM named place suggestions plus bilingual official transport stops;
  bounded online geocoding after an explicit click. OSM polygon centres are not entrance promises.
- Route directory, ordered stop lists, source-time suspension flags, road paths.
- Official DSAT timetable posters linked for every bus route; LRT links to its
  published operating hours. Poster headways are not invented exact departures.
- Start/end autocomplete, map picking, swapping and personal live GPS.
- Depart-at / arrive-by, companies Must/Normal/Ban, 0–60 minute change buffer,
  walking/waiting/change/ride/transfer limits and existing 0–200% importance sliders.
- Normal MOP cash/single fare alongside the selected card/student fare. Unknown
  bus concession prices remain unavailable, without invented discounts.
- Optional street-routed walk, cycle, taxi and driving estimates. Macau taxi
  tariffs/driving costs are unavailable; HK tariffs are never reused.
- Chinese/English layouts and responsive mobile/PWA access through the existing app.

## Deliberate safety limits

Bus **planning is OFF by default**. DSAT's public route catalogue and live bus
locations do not establish operating hours, exact departures or a timetable.
Opting in allows topology-only bus estimates: a nominal 7.5-minute wait,
18 km/h road-distance travel plus stop time. Neither confirms a bus is running.
These results must not receive live, timetable, added, changed or cancelled labels.
Stop suspensions are a snapshot, not continuous operational updates.

LRT uses published service windows and headway ranges (not exact departures).
Waiting is half the published maximum headway. Interstation running times are
estimates, calibrated to the published approximate total Taipa journey time.
Weekday public-holiday extensions are not inferred without a verified calendar;
the earlier weekday finish is used conservatively. Track offsets and the previous
service day are handled for trains passing downstream stations after midnight.

Walking access/transfer distances use a distance multiplier, not verified footpath
times. Bus paths are sliced along existing official pieces; disconnected source
pieces remain separate. A failed match hides the segment, never draws a chord.
LRT tracks are from OSM, not an official engineering alignment.

Ferries, casino/hotel shuttles, coach services and Hong Kong–Macau cross-border
journeys are **not supported**. No Macau arrival notifications are sent until
service/departure data can be verified. Existing Hong Kong notifications stay intact.

Rail fare sections count the Barra–Ocean and Lotus–Hengqin sea crossings twice.

is an endpoint. Connected paid-area LRT legs are priced as one journey. Card
concessions require the corresponding valid qualifying card.

## Reproduce imports

Keep cache OUTSIDE the repository; do not commit raw responses or extracts.
Python `osmium` is required for rail and landmarks; bus import uses standard library.

```powershell
python scripts/import-macau.py --cache C:/path/outside/repo/macau-cache
python scripts/import-macau-rail.py --cache C:/path/outside/repo/macau-cache
python scripts/import-macau-places.py --cache C:/path/outside/repo/macau-cache
```

Bus `--refresh` requests fresh public data; without it, cached responses are reused.
Generated data is split into files under 1 MB. The bus manifest's `importedOn`
records the import, not the individual upstream record update times.
